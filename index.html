TENNIS MATCH SCHEDULER

스마트 대진표 자동 생성 시스템 · 2코트 · 혼복 / 남복 / 여복

v2.0.0

📝 선수 입력

  • 이름, 성별(남/여), 등급(1~4) 입력
  • 최대 칸: 개인 최대 경기 수 제한 (공란=제한없음)
  • 행 우측 ✕ 로 개별 삭제
  • + 선수 추가 버튼으로 추가

🏆 등급 기준 (1~4)

  • 4레벨 — 상급 (대회 출전 수준)
  • 3레벨 — 중상급 (정기 동호인)
  • 2레벨 — 중급 (기초 완성)
  • 1레벨 — 초급 (입문 단계)

⚙ 알고리즘 v2.0

  • 성별·인원 비율로 남복/여복/혼복 최적 수 자동 계산
  • 남성 4명↑ → 남복 1경기 필수
  • 여성 4명↑ → 여복 1경기 필수
  • 등급 차 최소화 팀 배정
  • 균등 배분 검증 후 미달 시 최대 20회 재시도

📊 결과 해석

  • ✅ 양호 — 편차 1경기 이내
  • ⚠ 편차 — 최대치와 2경기 이상 차이
  • ⚠ 부족 — 3경기 미만 (인원 조정 권장)
  • 잡복 — 3M+1F 또는 1M+3F (부득이한 경우)
